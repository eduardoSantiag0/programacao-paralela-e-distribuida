## Programacao Paralela e Distribuída (PPD)

### Objetivos da disciplina: 

- Familiarizar o estudante com os conceitos e termos básicos de sistemas paralelos, implementação e uso de concorrência, 
- Apresentar os tipos de arquitetura mais usados, descrever o suporte necessário para a programação de tais sistemas e apresentar algumas aplicações.
- Tornar os alunos aptos a criar programas que usam eficientemente múltiplos recursos computacionais, locais e distribuídos, para execução paralela de código.
